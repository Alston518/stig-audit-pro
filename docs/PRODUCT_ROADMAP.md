# Product roadmap

Pilot follow-on work, not implemented in 0.2.0:

- CLI/headless scanning and scheduled scans
- CKL generation plus Excel and JSON reports
- Baseline comparison and trending
- Signed Windows installer and code signing
- SBOM generation, signed check packs, and release channels
- Organizational check-pack lifecycle
- Multi-vendor parser plugins
- Role-based review and approval

Release gates should include schema compatibility, signed artifacts, evidence migration, accessibility testing, real-device parser fixtures, and security-owner approval of applicability profiles.
